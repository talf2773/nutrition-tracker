# 🥗 מעקב תזונה קלינית

---

## הוראות העלאה — צעד אחר צעד

### שלב 1 — קבלת מפתח חינמי מ-Google

1. פתחי את הקישור: **https://aistudio.google.com/apikey**
2. התחברי עם ה-Gmail שלך
3. לחצי על הכפתור הכחול **"Create API Key"**
4. לחצי **"Create API key in new project"**
5. תראי מפתח שנראה כך: `AIzaSy...` — **העתיקי אותו ושמרי אותו בצד**

---

### שלב 2 — פתיחת חשבון GitHub (חינם)

1. פתחי: **https://github.com**
2. לחצי **"Sign up"** ← הירשמי עם אימייל וסיסמה
3. אמתי את האימייל שלך

---

### שלב 3 — יצירת פרויקט ב-GitHub

1. לאחר הכניסה, לחצי על **"+"** (פינה ימנית למעלה) ← **"New repository"**
2. בשדה **"Repository name"** כתבי: `nutrition-tracker`
3. ודאי שמסומן **"Public"**
4. לחצי **"Create repository"**
5. בדף שנפתח, לחצי על הקישור **"uploading an existing file"**
6. גרري את 4 הקבצים הבאים לתוך החלון:
   - `index.html` (מתוך תיקיית public)
   - `analyze.js` (מתוך תיקיית api)
   - `vercel.json`
   - `README.md`

   **⚠️ חשוב:** לפני שלוחצים Commit — צריך לשנות את נתיב הקבצים!
   - ל-`index.html` שנה ל: `public/index.html`
   - ל-`analyze.js` שנה ל: `api/analyze.js`

7. לחצי **"Commit changes"**

---

### שלב 4 — פתיחת חשבון Vercel (חינם)

1. פתחי: **https://vercel.com**
2. לחצי **"Sign Up"**
3. בחרי **"Continue with GitHub"** — זה מחבר אוטומטית את שני החשבונות
4. אשרי את ההרשאות

---

### שלב 5 — חיבור הפרויקט ל-Vercel

1. בדשבורד של Vercel לחצי **"Add New Project"**
2. תראי את הרשימה של ה-repositories מ-GitHub
3. ליד `nutrition-tracker` לחצי **"Import"**
4. בדף שנפתח — **אל תשני כלום**, לחצי ישירות **"Deploy"**
5. המתיני כ-30 שניות עד שתראי ✅ ו-**Congratulations**
6. תקבלי קישור כמו: `https://nutrition-tracker-abc.vercel.app`

---

### שלב 6 — הוספת המפתח של Google (חשוב!)

1. בדשבורד Vercel לחצי על הפרויקט `nutrition-tracker`
2. לחצי על **"Settings"** (בתפריט העליון)
3. בתפריט הצד לחצי **"Environment Variables"**
4. מלאי את השדות:
   - **Key:** `GEMINI_API_KEY`
   - **Value:** המפתח שהעתקת בשלב 1 (AIzaSy...)
5. לחצי **"Save"**
6. לחצי על **"Deployments"** בתפריט העליון
7. ליד הפריסה הראשונה לחצי על שלוש הנקודות `...` ← **"Redeploy"** ← **"Redeploy"**

---

### שלב 7 — בדיקה

פתחי את הקישור שקיבלת — האפליקציה מוכנה! 🎉
